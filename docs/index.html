Window switching, made direct

Built around the way a taskbar should behave.

No application-level ambiguity. Click the item you mean and Taskbar S brings that exact window forward.

01

One button, one window

Windows stay in stable order inside their application group. Focus changes never reorder your taskbar.

02

Clear launch feedback

An orange border appears as soon as an app begins launching, then hands off to the blue focus state when its first real window arrives.

03

Pin what matters

Keep favorite applications ready even after Quit. Taskbar S relaunches the app and requests a first window if the restarted process stays windowless.

04

Every display stays independent

Each monitor gets its own taskbar with only that display's windows. Spaces and application group order remain independent too.

05

Drag with confidence

Groups remain locked to the taskbar while you drag. Neighboring items slide out of the way with responsive animation.

06

Filters the noise

Tooltips, tab previews, menus, Caps Lock indicators, and other transient utility windows do not become taskbar items.

Everyday controls

Familiar actions, without hunting through the Dock.

Window buttons and pinned buttons provide direct mouse controls, while each display and Space keeps its own taskbar contents.

L

Left-click

Focus that exact window, or launch a pinned application that is not currently open.

M

Middle-click

Open the application when closed or request a new window when it is already running.

R

Right-click

Create a new window, minimize, restore, close, pin or unpin, and quit the application.

↔

Drag horizontally

Reorder a complete application group with taskbar-constrained movement and animated displacement.

●

Orange means launching

The launch state remains visible until a real application window appears, then clears automatically.

▣

Display-aware contents

Each monitor shows only its own windows for the active Space, with independent application-group ordering.

Feels integrated

Respects full screen, maximize, snap, and manual movement.

Automatic window layouts stop above the taskbar, while manually dragged windows remain free to move underneath it. Full-screen applications hide Taskbar S automatically.

  • Restores the previous size when a snapped window is dragged by its title bar
  • Compresses item widths only when screen space gets tight
  • Keeps temporary system UI out of the window list
  • Recovers windowless application launches after Quit

Get started

From download to taskbar in a minute.

  1. 1

    Download

    Get the latest Taskbar-S-0.2.0.dmg release.

  2. 2

    Move to Applications

    Open the DMG and drag Taskbar S into the Applications folder.

  3. 3

    Open once

    For the current non-notarized build, Control-click the app and choose Open.

  4. 4

    Grant Accessibility

    Enable Taskbar S in System Settings → Privacy & Security → Accessibility.
